# AUTOSERVICE

Landing page (alpha) for **Autoservice Oleh**, Kärntner Straße 105, 8053 Graz.

- `index.html` – single-page site, no build step. Open it in a browser or serve the folder statically.
- `assets/img/` – photos from the company Instagram @oleh_auto_graz.
- Design tokens, fonts and brand rules come from the "Autoservice Oleh" design system.

Open items before going live: clean vector logo, opening hours, confirmed prices, Impressum and Datenschutz pages.
